# 神算子 — 华山八字命理分析工具

基于朱辰彬《东方代码启示录》华山八字学理论的纯前端HTML测算工具，道教符箓仙韵UI风格。

## 功能

### 单人排盘（7个Tab）
- 输入姓名、性别、出生年月日时辰、出生城市
- 自动真太阳时校正（经度+夏时制1986-1991）
- 📜 **八字排盘**：四柱+纳音+藏干+属相+五行分布（图标进度条）+五行雷达图+五行解读
- ⚖️ **日主强弱**：得分明细+身强/身弱/中和深度解读（优势/注意/喜忌/发展建议）
- 🔟 **十神格局**：十神表格+格局定性+十神分布（图标彩色进度条）+逐一详解（性格/事业/财富/感情/建议）+综合说明
- ⚡ **冲合关系**：冲合总览+相合/相冲/相刑/三合分别详解+冲合化解总纲
- 🕐 **大运流年**：8步大运总览表（事业/婚姻/财富/健康吉凶）+当前大运详解+当前流年（宜/忌/方位/改运）+未来五年速览
- ⭐ **神煞星煞**：13种神煞（天乙贵人/文昌/桃花/驿马/华盖/劫煞/灾煞/将星/羊刃/学堂/禄神/天喜/天医）+逐一详解+统计
- 💡 **综合建议**：今日运势（吉凶/宜忌/方位/改运）+事业（主导十神→适合职业）+婚姻（五行属性+属相配对+日干相合）+财富（8步财运走势表）+健康（五行脏腑表+养生建议）+贵人方位

### 多人合盘（6个Tab）
- 支持2-6人同时排盘，5种关系：夫妻/亲戚/朋友/同事/领导
- 📜 **八字合盘**：兼容度评分+四维图标进度条+两人命盘并排+关键发现（有利/需注意/影响分析）
- 🔟 **十神合盘**：双向匹配分析（✅匹配/⚠️互斥+优点/需注意）+匹配度总评+改善建议
- ⚡ **冲合合盘**：四柱冲合总览+相合关系（和谐与羁绊）+相冲关系（变动与冲突）+冲合化解指南
- 🕐 **大运合盘**：大运同步关系状况表（🟢双方利好/🟡一方带动/🔴双方挑战）
- ⭐ **神煞合盘**：神煞相似度+逐一匹配表+改善建议
- 💡 **综合建议**：相处模式+共同事业+婚姻/关系+财富合作+健康互相关注+合盘总结

## 使用方法

1. 用浏览器打开 `shensuanzi.html`
2. 选择「单人排盘」或「多人合盘」
3. 填写出生信息
4. 点击「开始排盘」/「开始合盘」
5. 查看分Tab展示的分析结果
6. 在综合建议Tab右下角点击「导出PDF」保存报告

## 技术说明

- Google Fonts CDN加载书法字体（需网络）

## 理论体系

基于华山八字学核心规则（严格按《东方代码启示录》）：
- 年柱以立春为界，月柱以十二节令为界
- 磁极五行原则（异性方可相生）
- 十神简称：正财=财、偏财=才（与传统相反）
- 身强身弱判定（月令+通根+生扶）
- 大运排法（阳年男/阴年女顺排，起运=距节气天数÷3）
- 五行"少利多弊"原则（缺为优势，多为劣势）
- 13种神煞（按第23章星煞规则）

- 出生时间应尽量精确到时辰
- 出生城市用于计算真太阳时（经度校正）
- 节气交界日期（±1天）自动标注警告
- 命理分析反映概率趋势，并非绝对定数
- 后天努力和选择同样重要
